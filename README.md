# CDACF Simulation — Reproducibility Repository

This repository contains the complete simulation code, configuration, random seeds, and
statistical/plotting scripts underlying the manuscript:

> **A Stability-Aware Cross-Domain Adaptive Consensus Framework for Blockchain-Based
> Heterogeneous IoT Applications** (Discover Computing, submission 96ae8481-182e-4dd7-8b88-048b4e50ff08)

No third-party or publicly available datasets were used. All data reported in the manuscript
were generated by the code in this repository, using validation seeds 5–9 and primary-run
seed 42 as documented below.

---

## 1. Requirements

```
python >= 3.9
numpy
pandas
scipy
tabulate
matplotlib   # only needed if regenerating figures locally
```

```bash
pip install -r requirements.txt
```

## 2. Repository contents

| File | Purpose |
|---|---|
| `iot_integration_bayesian_v2.py` | Core simulator: both domain models (Traffic Management, Environmental Monitoring), the five static baseline mechanisms, the CDACF adaptive controller (Bayesian threat detector + stability-aware consensus layer), and the `run_simulation()` entry point. |
| `run_statistics.py` | Runs the five validation seeds for CDACF and all five static baselines in both domains, and computes the Mann–Whitney U / Holm–Bonferroni / rank-biserial statistics reported in **Table 8**. Outputs `statistics_summary.csv` and `results_per_seed.csv`. |
| `run_sensitivity.py` | Regenerates the one-at-a-time parameter sensitivity sweep (**Table 9**) and the stability-gate ablation study (**Table 10**) under the corrected simulator. Outputs `sensitivity_summary.csv` and `ablation_summary.csv`. |
| `results_per_seed.csv` | Per-seed, per-mechanism raw results (latency, throughput, mitigation-response) for both domains, seeds 5–9. Source data for **Table 7**. |
| `statistics_summary.csv` | Output of `run_statistics.py`. Source data for **Table 8**. |
| `sensitivity_summary.csv` | Output of `run_sensitivity.py`. Source data for **Table 9**. |
| `ablation_summary.csv` | Output of `run_sensitivity.py`. Source data for **Table 10**. |
| `config/` | Domain parameter files (5G/LoRaWAN telemetry constants, weight profiles from Table 4, attribute matrix from Table 3). |

**Note on plotting scripts:** the figure-generation scripts referenced in the manuscript's Data

## 3. Seeds

- **Validation seeds (multi-seed statistics, sensitivity, ablation):** `5, 6, 7, 8, 9` — matches the
  seed set used in the ADACON [4] validation protocol.
- **Primary/illustrative run (single-seed figures and the main comparison table, Table 6):** `seed = 42`.

Both are fixed and documented so that every run in the paper is exactly reproducible.

---

## 4. Reproducing each table

| Table | What it reports | Command |
|---|---|---|
| **Table 5** | Experimental configuration summary (domain parameters) | Static — see `config/traffic_domain.yaml` and `config/environmental_domain.yaml`; not script-generated. |
| **Table 6** | Per-mechanism performance within the CDACF run, seed 42, both domains | `python iot_integration_bayesian_v2.py --domain traffic --seed 42 --mechanism cdacf --report per-mechanism` <br> `python iot_integration_bayesian_v2.py --domain environmental --seed 42 --mechanism cdacf --report per-mechanism` |
| **Table 7** | Multi-seed statistical validation (mean ± SD, 95% CI, CV%), both domains | `python run_statistics.py` (writes `results_per_seed.csv`; aggregate mean/SD/CI/CV computed from this file — see `aggregate_table7()` in `run_statistics.py`) |
| **Table 8** | Complete pairwise Mann–Whitney U / Holm-corrected / rank-biserial r, CDACF vs. each static baseline, both domains, three metrics | `python run_statistics.py` → `statistics_summary.csv` |
| **Table 9** | One-at-a-time sensitivity (improvement threshold, dwell, Bayesian window) | `python run_sensitivity.py` → `sensitivity_summary.csv` |
| **Table 10** | Stability-gate ablation (full gate / dwell-only / threshold-only / disabled) | `python run_sensitivity.py` → `ablation_summary.csv` (same invocation as Table 9; both tables are written by the same script) |
| **Table 11** | Qualitative comparison with prior frameworks (Islam et al., Gutierrez et al., Tapwal et al., ADACON) | Not code-generated — literature comparison; see manuscript Section 5.2 and its cited sources. |

Command notes:
- `run_statistics.py` and `run_sensitivity.py` must be run from the same directory as
  `iot_integration_bayesian_v2.py` (they import from it directly).
- Both scripts run all five validation seeds internally — you do not need to loop over seeds
  manually; `VALIDATION_SEEDS = [5, 6, 7, 8, 9]` is defined once in `iot_integration_bayesian_v2.py`
  and imported by both.
- Expect `run_statistics.py` to take a few minutes (5 seeds × 2 domains × 6 configurations ×
  1,000 steps); `run_sensitivity.py` takes longer (5 seeds × 2 domains × 11 configurations
  across the sensitivity and ablation sweeps combined).
